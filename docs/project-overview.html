Systems are connected: Data pipeline failures automatically create incidents via DataPipelineIncidentBridge. Incident resolutions feed back into pipeline recommendations.

🔍

Python Parsing First

Never pass raw DTSX XML to the LLM (500 KB+ noise). DTSXParser.get_migration_summary() reduces to a clean 1–2 KB structured JSON of connections, data flows, and EXEC calls before LLM handoff.

🌐

Live DB Extraction

StoredProcReader fetches OBJECT_DEFINITION() (SQL Server), ALL_SOURCE (Oracle), pg_get_functiondef() (PostgreSQL). Falls back to static .sql file scan when DB is unreachable.

🕸️

Dependency Graph

Kahn's BFS topological sort groups stored procedures by topo_level. Level 0 = leaf (no deps). Same-level procs run in parallel Airflow TaskGroups. Cycle detection raises CycleDetectedError.

10 Code Patterns You Must Know
These patterns are non-negotiable across both systems. Every node, every API call, every type reference follows these conventions.
Pattern 1 — LangGraph StateGraph (not ReAct)
def node_name(state: AgentState) -> Dict[str, Any]:
    try:
        return {"result_key": value}
    except Exception as e:
        return {"error_message": str(e), "error_agent": "node_name"}

def should_continue(state) -> Literal["next", "error"]:
    return "error" if state.get("error_message") else "next"
Pattern 2 — All State Flows Through Kafka
# CORRECT
await producer.publish_event(
    topic="incident.enriched",
    event=payload,
    key=incident_id
)

# WRONG — never REST for internal state
# requests.post("http://backend/internal/update", ...)
Pattern 3 — FastAPI is Control Plane Only
@app.post("/api/v1/approve")
async def approve(req: ApprovalRequest):
    # Publish to Kafka — never run LangGraph here
    await producer.publish_event(
        topic="incident.approved",
        event=req.dict(),
        key=req.incident_id
    )
    return {"status": "queued"}
Pattern 4 — NL → Structured → Execute
// WRONG — never execute NL directly
// await api.createPipeline({ description: "load CSV" })

// CORRECT — always normalize first
const structured = await api.transformNL({
    description: "load CSV to BigQuery"
})
await api.createPipelineUnified(structured)
Pattern 5 — Pydantic v2 Contracts
from pydantic import BaseModel, model_validator

class UnifiedPipelineInput(BaseModel):
    model_config = ConfigDict(extra="forbid")  # fail on unknown
    input_type: Literal[
        "ui_structured", "natural_language", "dtsx_migration"
    ]
Pattern 6 — Idempotency Keys Everywhere
idempotency_key = f"{incident_id}:{event_type}:{timestamp}"

# Redis deduplication — 7-day TTL
if redis.set(
    f"idempotent:{agent_name}:{key}", "1",
    nx=True, ex=604800
):
    pass  # process — first time seen
Pattern 7 — Jinja2 Code Generation
# CORRECT — templates are frozen
template = template_manager.get_template(
    "file_ingest_dag.j2"
)
dag_code = template.render(
    feed_id=feed_id,
    source_config=source_config
)
# WRONG: dag_code = f"with DAG('{name}') ..."
Pattern 8 — Frontend Types from Canonical Only
// CORRECT
import { UnifiedPipelineInput } from '@/types/pipeline-canonical'

const input: UnifiedPipelineInput = {
    input_type: 'ui_structured',
    created_by: 'user@company.com',
    source: { source_type: 'file_csv', ... }
}

// WRONG: import from '@/types/pipeline' (deprecated)

Langfuse

Prompt Injection Defense

16 regex patterns via InputValidator detect direct instruction override, role manipulation, jailbreak attempts, encoding bypasses. Score < 0.5 → blocked + UNAUTHORIZED_ACCESS audit event.

🔐

Human-in-the-Loop

All PROD actions require explicit human approval. Kafka-driven pause at node_await_approval. 4-hour SLA before auto-escalation to on-call. Risk-based tiers: AUTO / STANDARD / SENIOR / EXECUTIVE.
